## 実行コマンド
共通して FORCE=1 で index/details/labels を再取得し、Python ワンライナーで JSONL→JSON 変換、`scripts.update_msdata` → `make validate-strict` → `make audit-*` を実施。

```
make scrape-index FORCE=1 TTL=1d
make scrape-details FORCE=1 TTL=1d RATE=1.0 LIMIT=0
uv run python - <<'PY' ...  # details.jsonl -> details.json
uv run python -m scripts.update_msdata -i cache/details.json
make validate-strict
make labels FORCE=1 LIMIT=0 TTL=1d
make audit-labels
make audit-index
```
