## 2. 表記揺れマッピング（行見出し → 最終パラメータ）

以下は代表的な「出現パターン」を最終パラメータにグルーピングしたものです。山括弧「＜＞」や全角/半角、順序の揺れは吸収します。

### コスト・耐久
- コスト ← Cost
- HP ← 機体HP

### 攻撃・耐性補正（通常/変形/変身）
- 射撃補正 ← 射撃補正, 射撃補正＜通常時＞
- 射撃補正_変形時 ← 射撃補正＜変形時＞
- 射撃補正_変身時 ← 射撃補正＜変身時＞
- 格闘補正 ← 格闘補正, 格闘補正＜通常時＞
- 格闘補正_変形時 ← 格闘補正＜変形時＞
- 格闘補正_変身時 ← 格闘補正＜変身時＞
- 耐ビーム補正 ← 耐ビーム補正
- 耐実弾補正 ← 耐実弾補正
- 耐格闘補正 ← 耐格闘補正

### 機動（速度/ブースト）
- スピード ← スピード, スピード＜通常時＞
- スピード_変形時 ← スピード＜変形時＞, スピード＜変身時＞
- 高速移動 ← 高速移動, 高速移動＜通常時＞
- 高速移動_変形時 ← 高速移動＜変形時＞, 高速移動＜変身時＞
- スラスター ← スラスター

### 旋回（度/秒）
- 旋回_地上_通常時 ← 旋回（地上）[度/秒], 旋回（地上）＜通常時＞[度/秒], 旋回＜通常時＞（地上）[度/秒], 旋回＜通常時＞[度/秒], 旋回[度/秒]
- 旋回_地上_変形時 ← 旋回（地上）＜変形時＞[度/秒], 旋回（地上）＜変身時＞[度/秒], 旋回＜変形時＞（地上）[度/秒]
- 旋回_宇宙_通常時 ← 旋回（宇宙）[度/秒], 旋回（宇宙）＜通常時＞[度/秒], 旋回＜通常時＞（宇宙）[度/秒]
- 旋回_宇宙_変形時 ← 旋回（宇宙）＜変形時＞[度/秒], 旋回（宇宙）＜変身時＞[度/秒], 旋回＜変形時＞（宇宙）[度/秒]
- 旋回_変形時 ← 旋回＜変形時＞[度/秒]（地上/宇宙の別が示されない稀な表記）

### スロット
- 近スロット ←（パーツスロット表の「近距離」）
- 中スロット ←（同「中距離」）
- 遠スロット ←（同「遠距離」）

### 購入・識別
- レアリティ ← レアリティ
- 必要階級 ← 必要階級
- 必要DP ← 必要DP
- 必要リサイクルチケット ← 必要リサイクル チケット, 必要リサイクルチケット

### その他
- カウンター ← カウンター
- 再出撃時間 ← 再出撃時間
- 格闘判定力 ← 格闘判定力

## 3. 出力JSONの別名（誤記）→ 正規キー（KEY_ALIASES）
- 射撃補則 / 射撃補生 → 射撃補正
- 格闘補定 → 格闘補正
- 旋回_通常時_地上 → 旋回_地上_通常時
- 旋回_通常時_宇宙 → 旋回_宇宙_通常時

（上記は、既に生成済みJSONのキーに誤記が混じっていた場合の修正規則です）

---

## 4. 値の正規化ポリシー（重要）
- 空白: 連続する空白は1つへ圧縮。半角カッコ内の注記（例: `( +25 )`）は除去。全角カッコは保持（例: `（地上）/（宇宙）`）。
- 数値抽出: 整数として抽出。単位/記号（`％/秒/[度/秒]` など）は除去。先頭の整数を採用。
  - 例: `78（盾装備時：75.7）` → `78` を採用。
- オプショナル数値: 取得できない場合はキーを未設定（nullは保存しない）。
