# ラベル正規化と監査のまとめ（2025-09-05）

本ドキュメントは、atwiki の機体ステータス表の「項目名（行見出し）」の表記揺れ監査と、JSON スキーマ/抽出ロジック/運用手順の更新点を、わかりやすく整理したものです。

## 背景と目的
- 目的: 機体ページのステータス項目名の揺らぎを網羅的に把握し、正規キーへ安全にマッピング。以後の更新で再発を自動検知。
- 対象: atwiki の MS 一覧/各機体ページの「ステータス表」「パーツスロット表」ほか。
- 方針: 監査（labels）で raw/normalized を収集→集計→マッピング拡充→スキーマに反映→取り込み実装に適用。

## 追加・変更点（要点）
- 監査コマンド（キャッシュ対応）を追加: `labels` サブコマンドと `audit_labels.py`。
- スキーマ（schema/msData.schema.json）を拡張（任意項目の追加）。
- 行見出し→正規キーのマッピング（FIELD_MAP）を拡充（変形/変身/表記の位置違いを吸収）。
- 出力 JSON の別名（誤記）の吸収（KEY_ALIASES）を共通モジュール化。
- キャッシュ設計（TTL=7日、条件付きGET、オフライン/強制更新）を導入。

## マッピング（行見出し → 正規キー）抜粋
- 基本系:
  - `Cost → コスト`, `機体HP → HP`
  - `旋回[度/秒] → 旋回_地上_通常時`（旧ページ互換）
- 変形/通常（山括弧の有無・順序違いを吸収）:
  - `スピード＜通常時＞ → スピード`, `スピード＜変形時/変身時＞ → スピード_変形時`
  - `高速移動＜通常時＞ → 高速移動`, `高速移動＜変形時/変身時＞ → 高速移動_変形時`
  - `射撃補正＜通常時＞ → 射撃補正`, `射撃補正＜変形時＞ → 射撃補正_変形時`, `射撃補正＜変身時＞ → 射撃補正_変身時`
  - `格闘補正＜通常時＞ → 格闘補正`, `格闘補正＜変形時＞ → 格闘補正_変形時`, `格闘補正＜変身時＞ → 格闘補正_変身時`
  - `旋回（地上）＜通常時＞[度/秒] → 旋回_地上_通常時`, `旋回（地上）＜変形時/変身時＞[度/秒] → 旋回_地上_変形時`
  - `旋回（宇宙）＜通常時＞[度/秒] → 旋回_宇宙_通常時`, `旋回（宇宙）＜変形時/変身時＞[度/秒] → 旋回_宇宙_変形時`
  - `旋回＜通常時＞[度/秒] → 旋回_地上_通常時`, `旋回＜変形時＞[度/秒] → 旋回_変形時`
- 購入系:
  - `レアリティ → レアリティ`, `必要階級 → 必要階級`, `必要DP → 必要DP`, `必要リサイクル チケット/必要リサイクルチケット → 必要リサイクルチケット`

## 正規化ルール（値）
- 余白: 連続する空白は 1 に圧縮。半角カッコ `()` 内の注記は除去（全角 `（ ）` は保持）。
- 数値抽出: 整数に統一。単位・記号は除去。
  - 例: `78（盾装備時：75.7）` → 先頭の整数 `78` を採用。
- オプショナル数値: 取得不可（空欄）の場合はキーを未設定（null は保存しない）。

## 実行コマンド（Make）
- 一覧取得（キャッシュ対応）: `make scrape-index TTL=7d`
- ラベル収集（30件など小規模）: `make labels LIMIT=30`
- 全件監査: `make labels LIMIT=0 && make audit-labels`
- 取り込み: `make import-details`（`cache/details.jsonl` → `msData.json`）
- 正規化（上書き）: `make normalize`
- 検証: `make validate` / 厳格: `make validate-strict`

## キャッシュ運用
- 既定 TTL: 7日（`--ttl 7d`）。
- オフライン: `--no-network` でキャッシュだけで動作。
- 強制更新: `--force` で TTL に関係なく再取得。
- 保存先: `cache/html/<slug>.html` + メタ `*.meta.json`（ETag/Last-Modified/sha256）。

## スポット検証の要点
- Ζガンダム（LV1 抜粋）: `スピード=135 / スピード_変形時=200 / 高速移動=215 / 高速移動_変形時=240 / 旋回_地上_通常時=69 / 旋回_宇宙_通常時=72`
- 「盾装備時」注記ありページ（133件）を再取り込み → 回転系の非整数値は 0 に。
- 例: `GQuuuuuuX（ジークアクス）_LV1` の `旋回_宇宙_通常時` は `78`（注記 `75.7` は参考値として無視）。
