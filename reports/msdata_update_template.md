# msData 更新レポート（YYYY-MM-DD）

## 取得・処理概要
- 取得日: YYYY-MM-DD
- ソース: atwiki モビルスーツ一覧（index）および各機体ページ
- 差分サマリ: `records: XXX -> YYY | +N -M ~K`

#### MS名_LVn
- 属性: 汎用/強襲/支援
- コスト: XXX
- HP: XXXX
- 射撃補正: XX
- 格闘補正: XX

**記載ガイドライン:**

- 出撃可否は「地上可」「宇宙可」の形式で記載（両方の場合は「地上可、宇宙可」）
- 環境適正はTrueのもののみ記載（複数の場合はカンマ区切り）
- レアリティや必要リサイクルチケットなど、該当する項目のみ記載

### 既存レコードの更新

#### MS名_LVn
- 項目名: 変更前の値 → 変更後の値
- 項目名: 追加 → 追加後の値（新規追加項目の場合）
- 項目名: 空欄 → 追加後の値（空欄から値が設定された場合）

**記載ガイドライン:**
- 既存更新は各機体ごとに見出し（`####`）で区切る
- 変更項目と前後の値を明記する
- 複数項目が変更された場合は、すべての変更を記載する
- 変更がない項目は記載しない

## テンプレート使用時の注意事項

1. **日付の置換**
   - `YYYY-MM-DD` → 実際の日付（例: 2025-11-07）
   - `YYYYMMDD` → 実際の日付（例: 20251107）

2. **差分サマリ**
   - `records: XXX -> YYY | +N -M ~K` の形式で記載
   - XXX: 更新前のレコード数
   - YYY: 更新後のレコード数
   - +N: 追加件数
   - -M: 削除件数
   - ~K: 更新件数

3. **新規追加機体の記載**
   - 各機体を `#### MS名_LVn` の見出しで区切る
   - 主要パラメータを網羅的に記載する
   - 該当しない項目は記載しない

4. **既存更新の記載**
   - 変更前後の値を `→` で区切って記載
   - 新規追加項目は `追加 → 値` の形式
   - 空欄から値が設定された場合は `空欄 → 値` の形式

5. **監査と検証結果**
   - 簡潔に結果のみ記載する
   - 重要な指標を明記する
