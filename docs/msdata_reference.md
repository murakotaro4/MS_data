# msData.json フィールドリファレンス

データ利用者向けの `msData.json` フィールド仕様です。機械検証の正は [`schema/msData.schema.json`](../schema/msData.schema.json) です。

## 1. 概要

- **形式**: JSON 配列
- **1 要素**: 機体の 1 レベル分のステータス
- **主キー**: `MS名`（`機体名_LVn` 形式。例: `ザクⅠ_LV1`）
- **件数**: 約 1,670 レコード（2026-07 時点で 1,671）
- **更新**: 毎日 18:00 JST に自動更新パイプラインが稼働し、差分があれば PR 経由で反映

## 2. 入手方法

| 用途 | パス / URL |
| --- | --- |
| データ本体（raw） | https://raw.githubusercontent.com/murakotaro4/MS_data/main/msData.json |
| 機械検証用スキーマ | [`schema/msData.schema.json`](../schema/msData.schema.json) |

スキーマは JSON Schema **draft-07** です。各レコードは `additionalProperties: false` のため、スキーマ未定義のキーは検証エラーになります。

## 3. フィールド一覧

列の意味:

| 列 | 説明 |
| --- | --- |
| フィールド名 | `msData.json` のキー |
| 型 | スキーマ上の型 |
| 必須 | `required` または anyOf 制約の有無 |
| 意味 | フィールドの意味（AGENTS.md / 実データに基づく） |
| 例 | 実データからの例 |

### 3.1 識別（2）

| フィールド名 | 型 | 必須 | 意味 | 例 |
| --- | --- | --- | --- | --- |
| `MS名` | string（`pattern`: `.+_LV\d+$`） | ○ | 機体名＋レベル。主キー相当。index 表記に正規化済み | `"ザクⅠ_LV1"` |
| `wiki_url` | string（uri） | — | atwiki 詳細ページの URL | `"https://w.atwiki.jp/battle-operation2/pages/351.html"` |

### 3.2 分類・入手（6）

| フィールド名 | 型 | 必須 | 意味 | 例 |
| --- | --- | --- | --- | --- |
| `属性` | string（enum: `汎用` / `強襲` / `支援`） | ○ | 機体タイプ | `"強襲"` |
| `コスト` | integer（0〜2000） | ○ | 出撃コスト | `100` |
| `レアリティ` | string | — | レアリティ表記 | `"☆"` |
| `必要階級` | string | — | 購入・使用に必要な階級 | `"二等兵01"` |
| `必要DP` | integer（≥0） | — | 購入に必要な DP | `2500` |
| `必要リサイクルチケット` | integer（≥0） | — | 購入に必要なリサイクルチケット | `10` |

### 3.3 出撃・環境適正（5）

出撃可否・環境適正は atwiki 固有 ID（`label_sortie_*` / `label_env_*`）を優先して解析し、不明時は旋回項目の有無から補完されます。

| フィールド名 | 型 | 必須 | 意味 | 例 |
| --- | --- | --- | --- | --- |
| `出撃_地上可` | boolean | — | 地上マップへの出撃可否 | `true` |
| `出撃_宇宙可` | boolean | — | 宇宙マップへの出撃可否 | `true` |
| `環境適正_地上` | boolean | — | 地上環境適正の有無 | `false` |
| `環境適正_宇宙` | boolean | — | 宇宙環境適正の有無 | `false` |
| `環境適正_水中` | boolean | — | 水中環境適正の有無 | `false` |

### 3.4 基本性能（6）

| フィールド名 | 型 | 必須 | 意味 | 例 |

| `スピード` | integer（≥0） | ○ | 通常時の移動速度 | `120` |
| `スピード_変形時` | integer（≥0） | — | 変形時の移動速度 | `185` |
| `高速移動` | integer（≥0） | ○ | 通常時の高速移動速度 | `175` |
| `高速移動_変形時` | integer（≥0） | — | 変形時の高速移動速度 | `225` |
| `スラスター` | integer（≥0） | ○ | スラスター容量 | `55` |

### 3.6 旋回（5）

スキーマは `allOf` 内の **anyOf** により、次のいずれか一方（または両方）を必須とします。

- `旋回_地上_通常時` がある、**または**
- `旋回_宇宙_通常時` がある

宇宙専用機は地上旋回を持たないことがあり、地上専用機は宇宙旋回を持たないことがあります。両方ある機体も普通に存在します。抽出時、`78（盾装備時：75.7）` のような表記は先頭整数（`78`）を採用します。

| フィールド名 | 型 | 必須 | 意味 | 例 |
| --- | --- | --- | --- | --- |
| `旋回_地上_通常時` | integer（≥0） | anyOf | 地上・通常時の旋回 | `48` |
| `旋回_地上_変形時` | integer（≥0） | — | 地上・変形時の旋回 | （変形機で付与） |
| `旋回_宇宙_通常時` | integer（≥0） | anyOf | 宇宙・通常時の旋回 | `48` |
| `旋回_宇宙_変形時` | integer（≥0） | — | 宇宙・変形時の旋回 | （変形機で付与） |
| `旋回_変形時` | integer（≥0） | — | 環境を区別しない変形時旋回（ソース表記に依存） | （該当機で付与） |

| `中スロット` | integer（≥0） | ○ | 中距離カスタムパーツ枠数 | `2` |
| `遠スロット` | integer（≥0） | ○ | 遠距離カスタムパーツ枠数 | `1` |

### 3.8 その他（4）

| フィールド名 | 型 | 必須 | 意味 | 例 |
| --- | --- | --- | --- | --- |
| `カウンター` | string | — | 地上／宇宙のカウンター攻撃内容 | `"地上：連打攻撃 宇宙：蹴り飛ばし"` |

## 4. fullst の説明

`fullst` は機体の強化（フル強化）リストです。各要素の形:

| キー | 型 | 必須 | 意味 |
| --- | --- | --- | --- |
| `name` | string | ○ | 強化項目名 |
| `level` | integer（≥0） | ○ | 強化レベル |
| `points` | integer \| null | — | 必要強化ポイント。「MSレベル毎必要強化値」に数値がある行のみ採用 |

`points` が `null` になるのは次の 2 パターンです。

1. **高 Lv 未掲載の補完**: 当該 MS レベルに強化値が掲載されていない場合、直前 Lv の強化内容で補完し、`points` は `null`
2. **「強行出撃」**: ソースが `-` や空欄でもエントリを生成し、`points` は `null`

例:

```json
[
  { "name": "複合拡張パーツスロット", "level": 1, "points": null },
  { "name": "強行出撃", "level": 1, "points": null }
]
```

## 7. スキルデータ

`msData.json` は**恒常値のみ**を保持します。スキルによるパラメータ変化はアプリ側で別 JSON と合成する設計です。

| ファイル | 役割 |
| --- | --- |
| [`data/skills_params.json`](../data/skills_params.json) | パラメータ変化スキルの定義（`skills[].name` / `levels[].effects`） |
| [`data/skill_owners_flat.json`](../data/skill_owners_flat.json) | スキル×シリーズ×機体 Lv の所持展開（`owners[]`: `skill`, `skill_level`, `series`, `ms_level`） |
| [`data/skills_catalog.json`](../data/skills_catalog.json) | 中間・参照用カタログ（発動条件・duration 等を含む） |
| [`data/skill_owners.json`](../data/skill_owners.json) | 中間・参照用の所持データ（シリーズ単位） |

JOIN の目安:

1. `skill_owners_flat` の `series` + `ms_level` と、`msData` の `MS名`（シリーズ名と `_LVn`）を対応付ける
2. 同レコードの `skill` / `skill_level` で `skills_params` の定義を引く
3. `effects`（`op: add|mul` 等）を恒常値へ適用

合成プレビュー（`msData` には埋め込まない）:

```bash
uv run python -m ms_data.tasks preview-params
```

出力先: `derived/ms_params_preview.json`

## 8. 注意事項

- 出典は atwiki（バトオペ2 非公式 wiki）のデータです。公式データではありません
- 正確性は無保証です。差分・監査レポート（`reports/`）とあわせて利用してください
- スキーマは `additionalProperties: false` です。フィールド追加・改名はスキーマ改訂を伴います
- 本リファレンスは利用者向けの説明です。機械検証は必ず `schema/msData.schema.json` を正としてください
